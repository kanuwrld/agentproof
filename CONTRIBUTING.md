# Contributing

Focused fixes and new deterministic assertion types are welcome.

1. Open an issue describing the contract or bug.
2. Use fictional fixtures with no credentials or personal data.
3. Add tests for passing and failing behavior.
4. Run `python -m unittest discover -s tests -v`.
5. Keep runtime dependencies at zero unless the tradeoff is discussed first.

Security reports belong in a private GitHub advisory, not a public issue.
