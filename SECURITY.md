# Security Policy

## Data boundary

AgentProof reads local JSON suites and does not make network requests. Test
fixtures can still expose prompts, customer data, credentials, or proprietary
outputs. Commit fictional or explicitly sanitized fixtures only.

## Reporting a vulnerability

Do not open a public issue for an unpatched vulnerability. Use GitHub private
vulnerability reporting and include affected versions, reproduction steps,
impact, and any suggested fix. Expect acknowledgement within five business days.
